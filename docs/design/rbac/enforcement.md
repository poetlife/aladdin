# RBAC — 鉴权决策

## 背景与目标

定义"给定一个主体、一个权限码、一个作用域，如何得出允许或拒绝"，以及这个结论如何被记录、缓存与失效。

本子模块是所有鉴权判定的**唯一决策语义来源**。服务端、前端、CLI 任何一处描述"什么算有权限"，都必须与本节一致；出现分歧时以本节为准，并修正实现。

## 功能行为

### 决策输入与输出

一次判定接收三样东西：**主体、权限码、作用域**。产出一个二元结论：允许或拒绝。

拒绝时同时产出**原因**，原因取值是一组固定的枚举语义（不是自由文本），使得前端与 CLI 能据此给出可区分的提示：

| 原因 | 含义 | 客户端应有的表现 |
|------|------|-----------------|
| 无匹配授权 | 主体确实没有这条权限 | 提示权限不足，不重试 |
| 作用域不符 | 主体有此权限，但被授予的作用域不覆盖本次请求 | 提示需要更高层级授权 |
| 会话失效 | 凭证过期或已撤销 | 引导重新登录 |
| 主体不存在 | 凭证有效但主体已被删除或停用 | 引导联系管理员，不重试 |

### 判定顺序（必须先做的一步）

判定按固定顺序推进，**顺序本身是行为的一部分**：

1. 主体是否已确认且有效——若否，直接以"会话失效"或"主体不存在"拒绝。
2. 收集主体在目标作用域及其所有祖先作用域上生效的全部角色。
3. 展开这些角色（含继承）得到权限码集合。
4. 检查请求的权限码是否被该集合覆盖——覆盖包括精确匹配与通配匹配。
5. 全部命中失败则拒绝，原因为"无匹配授权"。

**默认拒绝**：不存在任何显式授权即拒绝。不做"默认可读"之类的例外。

**没有显式拒绝规则**：模型中没有 deny 条目（见 [role-model.md](role-model.md)）。因此判定不需要"先看拒绝再看允许"的两段式，也不存在拒绝优先级的歧义。

### 决策点（PEP）

需要在何处调用判定，是行为约定而非实现细节：

| 决策点 | 触发时机 | 拒绝时的后果 |
|--------|---------|-------------|
| 服务端接口入口 | 每个受控 gRPC 方法被调用时 | 请求不进入业务逻辑，返回拒绝 |
| 服务端数据读取路径 | 涉及作用域过滤的列表类接口 | 结果集只包含主体有权限的作用域内的数据 |
| CLI 命令执行前 | 命令参数解析完成后 | 命令不发起远端调用，直接以失败退出 |
| 前端路由进入前 | 路由切换时 | 不渲染目标页面，跳转到无权限提示 |
| 前端控件渲染前 | 组件挂载时 | 不渲染该控件 |

前两者是安全边界；后三者是体验优化。**后三者被绕过不影响安全性，前两者被绕过即安全漏洞。**

### 缓存与失效

- 判定结果**可以缓存**，但缓存必须限定在"主体 × 作用域"这一维度上，且必须有明确的失效路径。
- 角色或绑定关系发生变更（见 [role-model.md](role-model.md) 的变更阶段）后，受影响的缓存条目必须在"缓存失效"阶段被清除，不允许等待自然过期。
- 缓存不可用时（如存储故障）应**退化为实时查询**，而不是退化为允许或拒绝全部请求。
- 缓存不得跨主体复用：任何以权限码为唯一键的缓存都是错误的。

### 审计留痕

每一次判定（无论允许还是拒绝）都必须留痕，字段要求见 [observability.md](../../observability.md) 的"鉴权相关的强制字段"。

额外要求：

- **拒绝必须留痕，且比允许更重要**。允许可以采样，拒绝不可采样。
- 留痕内容不得包含凭证原文或敏感业务数据，只记录主体标识、权限码、作用域与结论。
- 同一 `trace_id` 下的多次判定（如列表接口逐条过滤）需可区分，避免日志被淹没。

## 边界与约束

本模块**明确不处理**：

- 认证（凭证校验、令牌签发）。
- 资源归属判断（"这条数据是不是他的"）。
- 限流与配额——即使有权限，也可能因限流被拒，这属于另一个模块。
- 角色与权限数据的**管理**（增删改角色），属于 [role-model.md](role-model.md) 描述的管理接口，本模块只负责消费。

约束：

- 判定的时间复杂度必须与主体持有的角色数成正比，**不得与系统中的角色总数成正比**。这是不允许在判定路径上做全量扫描的硬性要求。
- 判定路径上不允许出现网络调用等待人工审批之类的阻塞操作。

## 可验证性与长程执行

**非长程任务，无需中途校验。** 单次判定是纯同步的即时计算，不涉及多阶段推进，也不存在"中途失败需要恢复"的场景；判定要么给出结论，要么因存储不可用而快速失败并退化为实时查询。

需要长期观测的是**决策结果的分布**，而非单次判定的进度：

| 观测维度 | 用途 | 对应指标 |
|---------|------|---------|
| 按权限码统计的拒绝率 | 发现角色配置错误导致的集体拒绝 | `aladdin_rbac_decision_total` |
| 决策耗时分布 | 发现缓存失效或存储退化导致的延迟劣化 | `aladdin_rbac_decision_duration_seconds` |
| 同一主体在短时间内的大量拒绝 | 发现凭证问题或异常调用 | 同上，按 `subject_id` 聚合 |

## 依赖关系

| 依赖对象 | 交互方式 |
|---------|---------|
| 角色与权限模型 | 读取主体、角色、绑定关系与作用域规则 |
| 持久化存储 | 经 `rbac.Store` 读取，缓存未命中时访问 |
| 可观测性 | 输出决策日志与决策指标 |
