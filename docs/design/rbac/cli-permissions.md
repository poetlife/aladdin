# RBAC — CLI 接入

## 背景与目标

描述 cobra 命令行工具如何使用权限：凭证从哪来、命令如何映射到权限码、被拒绝时如何呈现。

与前端同理，**CLI 不承担安全职责**。CLI 的本地校验只是为了在发起网络请求前给出更快的反馈；真正的判定在服务端。CLI 与服务端走的是**完全相同的 gRPC 鉴权链路**，不存在"CLI 专用后门"。

## 功能行为

### 凭证来源

CLI 的凭证按固定优先级从以下来源获取，**先命中者胜出**：

| 优先级 | 来源 | 用途 |
|--------|------|------|
| 1 | 命令行参数显式传入 | 临时身份、CI 场景 |
| 2 | 环境变量 | 无人值守与 CI 的首选 |
| 3 | 本地凭证文件 | 交互式登录后的默认来源 |

约定：

- 凭证文件必须**只有属主可读**；权限过宽时拒绝使用并提示，而不是"警告后继续"。
- 凭证文件中的内容不得出现在任何日志、错误信息或 `--debug` 输出中。
- 未找到任何凭证时，提示用户执行登录命令，而不是提示"权限不足"。

### 命令到权限码的映射

- 每个需要权限的子命令**显式声明其所需权限码**，声明方式与 gRPC 方法一致（同一份 proto 定义派生）。
- 未声明权限码的命令默认**不执行**。与公开方法同理，需要免鉴权的命令（如登录、查看版本）必须进入显式白名单。
- 不允许在命令实现内部临时拼装权限码字符串——一律引用生成的常量。
- 命令所需的**作用域**来自命令参数（如 `--scope`），未提供时使用凭证自身绑定的默认作用域；**不得默认使用全局作用域**。

### 危险操作的二次确认

以下类别的命令在交互式终端下必须二次确认，且确认信息中要**明确列出受影响的资源与作用域**：

- 删除类操作（删除角色、解绑权限）
- 范围广泛的批量操作
- 会改变权限边界的操作（授予角色、发布策略）

约定：

- 非交互式终端（CI、管道）下**不弹确认**，改为要求显式传入 `--yes` 标志；未传入则直接失败。**不允许默认放行**。
- 二次确认不能替代鉴权：确认通过后仍必须经服务端判定。

### 输出与退出码

- 权限不足时，CLI 必须**明确区分"权限不足"与"未登录/凭证过期"**，与 [server-permissions.md](server-permissions.md) 的拒绝语义一一对应。
- 退出码区分不同失败类别，使得脚本能据此分支处理：

| 情形 | 退出码语义 |
|------|-----------|
| 成功 | 0 |
| 用法错误（参数不合法） | 与参数解析失败一致 |
| 未认证 / 凭证过期 | 独立值，便于脚本触发重新登录 |
| 权限不足 | 独立值，脚本不应重试 |
| 服务端不可用 | 独立值，脚本可退避重试 |

具体数值在实现时确定并在 `--help` 中说明；**关键是四类必须互不相同**。

- 默认输出为人类可读文本；`--output json` 时为机器可读，且**错误也走 JSON**，便于脚本解析失败原因。

### 本地预检的边界

CLI 在与服务端建立连接前**可以**做的本地判断仅限于：

- 凭证是否存在、是否明显过期（依据凭证自身的过期时间字段）。

CLI **不得**在本地缓存并复用权限判定结果来决定是否发起调用。原因：本地缓存的判定无法感知服务端的角色变更，会导致"服务端已收回权限，CLI 仍在放行"。

本地预检失败时的提示必须说明"这是本地判断，未与服务器确认"，避免用户误以为结论权威。

## 边界与约束

本模块**明确不处理**：

- 服务端判定逻辑的任何副本。
- 凭证的签发与刷新（属于身份认证模块）；CLI 只消费凭证，过期后引导重新登录。

约束：

- CLI 不得提供任何绕过服务端鉴权的开关（如 `--skip-auth`、`--insecure-permissions`）。这类开关一旦存在，就一定会被用在生产环境。
- `--debug` 输出中同样不得包含凭证原文。

## 可验证性与长程执行

**非长程任务，无需中途校验。** 单条命令的鉴权是同步的即时判定。需要长期保证的是映射与退出码的稳定性：

| 核查项 | 判据 |
|--------|------|
| 命令覆盖 | 每个需鉴权的子命令都声明了权限码，或命中公开白名单（静态检查，构建期执行） |
| 无绕过开关 | 不存在跳过鉴权的标志（静态检查） |
| 退出码稳定 | 四类失败的退出码互不相同，且有测试固定（脚本契约，变更即破坏性变更） |
| 凭证不泄露 | `--debug` 与错误输出中不含凭证原文（测试断言） |

## 依赖关系

| 依赖对象 | 交互方式 |
|---------|---------|
| 服务端 gRPC 接入 | 经 gRPC 客户端调用，消费其拒绝语义 |
| 身份认证 | 获取与刷新凭证；CLI 不实现签发 |
| proto 定义 | 权限码常量与客户端 stub 由 proto 生成 |
| 配置加载 | 凭证与目标环境地址经统一配置入口读取 |
