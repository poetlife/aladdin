# Web 界面 — 文档区对 agent 可读

> 文档区**长在界面的哪里**、准入是什么、章节怎么加，见 [docs-area.md](docs-area.md)。本文件只管另一件事：**读它的不只是人**——一个不执行 JS 的抓取方（agent、爬虫、`curl`）怎么拿到同一份正文。

## 背景与目标

站内文档既给人看，也应该给 agent 看。但"给人看"不等于"给 agent 看得到"：前端是一个 SPA，静态产物里只有一个 `<div id="root"></div>`，正文要靠 JS 渲染出来。实测（2026-10-09，部署实例）不执行 JS 时：

- `/docs/galaxy` 返回的是空壳，**正文一个字都没有**。
- `/llms.txt`、`/docs/galaxy.md`、`/robots.txt` 都返回 `200 text/html`——SPA 兜底把任意路径都接成了首页。那是个**软 404**：抓取方以为地址存在，拿到的却是应用空壳。

这不是"让 AI 搜索更愿意引用"（GEO）那一层的事，它更靠前：**agent 能不能读到文档**。做好之后 GEO 自然受益。

成功的衡量标准：

1. **不执行 JS 也读得到正文**，且读到的与执行 JS 后看到的是同一段字。
2. **一份正文，多种形态**：人看的页面、agent 读的 Markdown、agent 用的索引，全部由同一份源派生，不为 agent 再手写一份。
3. **找不到就是找不到**：静态资源类路径不存在时给 404，不再兜底成首页。
4. 这三条在**本地开发环境与线上都成立**——只在一边成立等于没成立。

### 非目标

- **不做运行时 SSR 服务**。预渲染发生在构建期，产物仍是静态文件。
- **不把整个应用改成预渲染**。只有公开的文档区那几页。
- **不改 `/api-docs/` 的生成方式**。它本来就是生成的静态页，只在索引里列一条链接。

## 三层，同一份内容

| 层 | 谁读 | 在哪 |
|----|------|------|
| 预渲染 HTML | 人、普通爬虫、不执行 JS 的客户端 | `/docs/<章>` 的静态 HTML，正文就在里面 |
| 章节 Markdown | agent | `/docs/<章>.md`；请求头要 `text/markdown` 时 `/docs/<章>` 也直接给这一份 |
| 索引 | agent | `/llms.txt`（各章标题、一句说明、`.md` 链接），`/llms-full.txt`（各章拼接，一次取完） |

HTML 的 `<head>` 里有真实的 `<title>`、`<meta name="description">`、`<link rel="canonical">`，以及指向 Markdown 版的那条 `<link rel="alternate" type="text/markdown">`。

**规范地址写的是相对路径**（`/docs/galaxy`）。绝对地址要求知道部署域名，而域名是实例值、不进仓库（见 [../deploy.md](../deploy.md) 的可验证性表）；相对地址由抓取方按当前地址解析，结论一样。

## 单一真源

正文只有一处：`web/src/pages/docs/chapters/<slug>.md`。**页面渲染它，`.md` 与 `llms.txt` 由它派生**——`# 标题` 由清单里的 `title` 拼，各章 Markdown 就是源文件本身。

因此"页面改了而 `.md` 没跟上"在结构上不可能发生：两侧读的是同一个字符串。这条由 `chapters/artifacts.test.ts` 钉住，不靠人工比对。

章节清单也只有一处（`chapters/manifest.tsx`）：索引页、路由表、`.md`、`llms.txt`、预渲染的路径列表全部从它派生。加一章只改那里加一条、放一个同名 `.md`。

**协议取值从实现里取。** 通道那一章写的是对外契约（通道名、协议版本、消息类型），正文里因此写的是 `{{frame.channel}}` 这样的占位符，由 [frame-channel.ts](../../../web/src/pages/galaxy/frame-channel.ts) 的常量填上。手抄一份的表现是协议改了而文档不声不响地继续说旧的；不认识的占位符**直接抛错**，不停在正文里。

### 章节源的形状

一章一个 `.md`，`## ` 开一行即起一节——页面上是一张卡片，Markdown 里是一个小节。扫描时跳过围栏代码块：命令与示例 JSON 里出现 `## ` 是内容，不是分节。

这条形状约定是"页面读同一份源"的代价：不约定的话，页面得另有一份"哪几段配哪张卡片"的清单，那又是一份会漂的定义。

## 构建期预渲染

预渲染是**客户端构建之后的一趟**（`web/prerender/`）：用与浏览器**同一张路由表、同一棵组件树**把公开路径渲染成 HTML，套进客户端构建出来的 `index.html` 模板，写到 `dist/docs/<章>/index.html`。

不做运行时 SSR 服务，也不另写一套"静态版页面"——那会是同一件事的第二份实现，两份必然漂。

样式走 cssinjs 的缓存抽出来随 HTML 一起发：不抽的话静态 HTML 是一份**没有样式**的正文，不执行 JS 的读者看到的是浏览器默认排版。

**抽出来的那一份必须能被撤掉。** 构建时不知道访问者选了哪一档主题，静态页只能是一档；而运行期 cssinjs 把自己的样式插在 `head` **最前面**，静态那一份因此永远排在它后面——两者的选择器都是 `:root` 级零特异性，排在后面的赢。不撤的话，暗色访问者看到的是一张亮色的页面，**而且怎么切都切不回来**。客户端因此：

- 挂载前撤掉 `style[data-prerender]`，让运行期那一套按当前主题生效；
- **不 hydrate，整棵重新渲染**。水合要求两侧第一帧一致，而静态 HTML 里的内联样式是按亮色定下的字面值，客户端的取值可能不同，React 又不会回头改这些属性——于是页面停在静态那一档上，只能靠一次交互刷新过来。要让水合对得上，就得让客户端第一帧故意渲染成亮色、挂载后再改，那等于把"第一帧说的不是实话"写进主题那一层，而收益只是省下重建这十几个节点。

## 部署形态上的三条

三条都在 [deploy/nginx-aladdin-site.conf](../../../deploy/nginx-aladdin-site.conf)，与开发期 Vite 的中间件**一一对应**（[web/vite.config.ts](../../../web/vite.config.ts)）——两处各写一份就会漂，而漂的表现是"线上取到的是文档、本地取到的是首页"，只在一边复现。

1. **预渲染出来的目录由 `try_files $uri $uri/` 找到**。`/docs/cli` 落到 `docs/cli/index.html`，不需要任何额外规则。
2. **`.md` / `.txt` 找不到就是 404**。少了这条，未知路径会被 SPA 兜底接成 200 首页——软 404，正是本文件开头那件事。
3. **`Accept: text/markdown` 时 `/docs/<章>` 直接给 `.md`**。只对**章**这一级生效：放开到任意路径会让一个带该请求头的浏览器把整个应用取成 404。

`robots.txt` 允许抓 `/docs/` 与两个 llms 文件，其余 `Disallow`。它是真文件（`web/public/robots.txt`），不是兜底出来的页面。

## 可验证性与长程执行

| 核查项 | 判据（验证手段） |
|--------|----------------|
| 不执行 JS 也读得到正文 | 每一页的预渲染 HTML 里有一段可见正文（`server-render.test.tsx`） |
| 两条路径读到同一段字 | 预渲染 HTML 的文字与客户端渲染出的文字逐字相等（同上） |
| `.md` 与页面对得上 | 产物里的正文就是章节源那一份（`artifacts.test.ts`） |
| 索引里的链接都可达 | `llms.txt` 的每条链接都指向一份真实产物（同上） |
| 占位符都填上了 | 产物里不残留 `{{…}}`（同上） |
| 正文不含实例值 | 产物里的地址都是相对路径（同上） |
| 静态样式会被撤掉 | `style[data-prerender]` 标记在（`public-pages.test.ts`），撤销在（`main.tsx`） |
| 未登录读得到 | 不带凭证按真实路由表渲染 `/docs/*` 仍出正文（`routes.test.tsx`） |
| 线上与 dev 一致 | **人工冒烟**：`curl` 三个地址，判据见下 |

人工冒烟（部署后）：

```bash
curl -s https://<域名>/docs/galaxy    | grep -q 'asset://'   # 正文在 HTML 里
curl -sI https://<域名>/llms.txt      | head -1              # 200，且 content-type 不是 text/html
curl -s  https://<域名>/not-exist.md  -o /dev/null -w '%{http_code}\n'   # 404
```
