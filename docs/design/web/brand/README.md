# 品牌标识

> 本目录是 aladdin **"这个产品长什么样"** 的唯一信源：形状、颜色、各种尺寸的产物怎么来。

## 现在用的是什么

一个**一笔写成的标识**：丝带自左下起笔，向右上收束、变细，最终在顶端展开成一枚四角星光。青（`#00C2FF`）到紫（`#8B5CF6`）的渐变顺着这一笔走——尾部是青的，星光那一端是紫的。暗色版把两端各提亮一档（`#22D3FF` / `#A78BFA`），并给形状加一层柔和发光。

四角星光那一段是"许愿即生成"那句话的落点：丝带是笔迹，星光是结果。它没有画出神灯本身——第一轮试过具象的油灯，在 16×16 下只剩一个认不出的色块（见下面「怎么来的」）。

## 两个版本，两种底色

| 版本 | 底色 | 发光 | 用在哪 |
|------|------|------|--------|
| 浅色 | 白 | 无 | 浅色主题的界面、浅色标签栏 |
| 暗色 | 近黑（`#111114`） | 有 | 暗色主题的界面、暗色标签栏 |

发光用高斯模糊，不用外描边：模糊在深底上表现得像光晕，描边会变成一圈假边框。渲染器不支持滤镜时发光**整个消失**，剩下的是与浅色版一样的实心形状——降级的方向是对的（少一层光，不是少一个形状）。

## 怎么来的

1. **第一轮**（具象神灯方向）：蓝色实心灯、紫色渐变灯、单线灯。**被否**——不够科技感，且 16×16 下几乎认不出。
2. **第二轮**：字母 A + 星光、流动丝带球 + 星光。进入候选，但球体那版靠多层半透明堆出体积，缩到 favicon 尺寸糊成一团；字母 A 那版辨识度最好，却把品牌收窄成了"A 就是阿拉丁"这一个读法。
3. **第三轮**：一笔丝带卷成星光、渐变晶体 + 顶部星光。**2026-10-10 选定前者**（issue #70 里的候选 G）。
4. **重绘**：最终文件是**按草稿重绘的 SVG 矢量源**，不是把栅格草稿自动描摹一遍。描摹出来的是几百段碎路径，改不动、也压不小；重绘的是十几段贝塞尔曲线，形状可以在编辑器里直接调。

重绘时相对草稿改了一处：**尾梢加粗了一点点**。草稿的尾巴收得极细，16×16 下整条尾巴会消失，只剩一个孤零零的星——而"一笔写成的丝带"正是这个标识区别于普通星形图标的地方。

### 草稿与提示词

草稿图在 **`brand-drafts` 分支**的 `docs/design/web/brand/drafts/`，仅供挑选，不合入 main。

**前几轮生成草稿时用的提示词没有记进仓库**，因此这里不补写——事后编一个"当时的提示词"只会让人以为照它重跑能得到同一批图。要再开一轮时，把提示词连同产出一起记到本节。

选定方向的描述（供下一轮直接复用）：

> 扁平几何风格的产品标识，一笔写成的渐变丝带：自左下起笔向右上收束，尾端渐细，顶端展开成一枚四角星光。青到紫的线性渐变沿这一笔走。无文字、无描边、无阴影，纯色块。同一形状需要浅色（白底，饱和渐变，不加发光）与暗色（近黑底，柔和发光）两版。

## 再生成

改了 `aladdin-mark.svg`（或它的暗色版）之后：

```bash
docs/design/web/brand/generate-icons.sh
```

然后**把 web/ 下变动的产物一起提交**。这个脚本不进 CI：favicon 是浏览器在首屏之前就要的东西，没有让流水线在发版时渲染一遍的理由。它是维护者在自己机器上跑的一次性工具，依赖 macOS 的 `sips` 与 `python3`——换机器重跑得到的像素可能有微小差异，那不是问题，源是 SVG，栅格产物只是它在若干尺寸上的快照。

改动形状时有两个坑，脚本里各有一段说明，这里再说一遍：

- **`<defs>` 必须留在顶层**。放进带缩放的 `<g>` 里，`userSpaceOnUse` 的渐变会跟着被缩放，结果是一片空白——不报错。
- **路径里的坐标全是 viewBox 单位**，与导出尺寸无关。混进导出尺寸的表现是：一个尺寸正常，其余尺寸整个图形跑到画布外。

## 边界

- **只有标识**：字标、字体、配色体系不在本目录。字标就是界面字体，不另做一套。
- **不改发布页（用户作品）的图标**：那是用户自己的站点，被我们的品牌盖掉才是问题（见 [../galaxy/publication.md](../galaxy/publication.md)）。
- **不做完整 VI**：没有标准制图、没有最小留白规范、没有禁用示例。这一类规范要有人维护才有意义，眼下没有。
